# карточка товара для Teaboom

Тестовое задание

## О проекте

Адаптивная верстка верхнего блока карточки товара «Ананасовый улун» для интернет-магазина Teaboom.

## Реализовано

- Отображение изображения и названия товара
- Выбор фасовки
- Динамическое изменение артикула, текущей и старой цены при выборе фасовки
- Визуальное выделение выбранной фасовки
- Интерактивные кнопки
- Переключение вкладок с информацией о товаре
- Адаптивная верстка

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, Медиа-запросы)
- JavaScript
- БЭМ

## Запуск проекта

1. Скачайте репозиторий
2. Откройте `index.html` в браузере
